# Анатолій Лутай – Особисте резюме

Особисте онлайн-резюме з демонстрацією моїх професійних навичок, проєктів та досвіду роботи.  
Сайт створено за допомогою HTML, CSS та JavaScript і підходить для презентації портфоліо потенційним роботодавцям.

## Технології

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript
